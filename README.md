## El problema

Consultar y operar el punto de venta con lenguaje natural.

## Qué hace

- Chat con el agente del punto de venta

## Cómo está construido

**Tipo:** Página estática + Base44

Una página que llama a la API de Base44.

**Tecnologías**

- HTML y JavaScript en un archivo
- API de Base44

**Backend**

- API de la app Base44

**Datos**

- Definidas en la app Base44

## Datos sensibles

Datos comerciales.

## Reglas del proyecto

- Nunca incluir tokens en el HTML

## Pendientes conocidos
